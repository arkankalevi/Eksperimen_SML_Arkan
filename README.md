# Eksperimen_SML_Arkan

Eksperimen & preprocessing dataset **Telco Customer Churn** (klasifikasi churn pelanggan).

```
Eksperimen_SML_Arkan
├── telco_churn_raw/                     # dataset mentah
│   └── Telco-Customer-Churn.csv
└── preprocessing/
    ├── Eksperimen_Arkan.ipynb           # data loading, EDA, preprocessing (berdasarkan Template Eksperimen MSML)
    └── telco_churn_preprocessing/       # hasil preprocessing (siap dilatih)
        ├── train.csv
        └── test.csv
```

Menjalankan ulang: buka `preprocessing/Eksperimen_Arkan.ipynb`, jalankan semua cell dari atas ke bawah
(path data relatif, jalankan dari folder `preprocessing/`).
